Database security

Guarded at the database itself.

Every read and write is checked against per-person protection rules, before it ever touches your data. No invite, no access.

  • Per-person rules: each person's ledger opens only to members you invited.
  • Reader vs. writer: readers can view, writers can add, enforced server-side, not just in the app.
  • Verified totals: balances are recalculated and validated on the server, so nobody can forge them.
database.rules 
database {
  match /people/{personId} {
    // only invited members can read
    allow read: if isMember(personId);
    // writers add entries, totals stay honest
    allow write: if isWriter(personId)
                 && validBalance(personId);
  }
}
